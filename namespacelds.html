van der Corput sequence

The vdc function is calculating the van der Corput sequence value for a given index \(n\) and base \(b\). It returns a double value.

The sequence is defined as:

\[ \phi_b(n) = \sum_{k=0}^{\infty} \frac{a_k}{b^{k+1}} \]

where \(a_k\) are the base- \(b\) digits of \(n\):

\[ n = \sum_{k=0}^{\infty} a_k \, b^k \] 

*     Base 2 Example:
*     count=1 -> 0.5  (0.1 in base 2)
*     count=2 -> 0.25 (0.01 in base 2)
*     count=3 -> 0.75 (0.11 in base 2)
*     count=4 -> 0.125(0.001 in base 2)
