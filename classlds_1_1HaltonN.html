Detailed Description

template<std::size_t N>
class lds::HaltonN< N >

N-dimensional Halton sequence generator with runtime-polymorphic bases.

Uses VdCorputBase pointers to support arbitrary prime bases at runtime, dispatching to the optimal compile-time (VdCorputWrap) or runtime (VdCorputDynamic) implementation depending on the base value.

Template Parameters
NNumber of dimensions.
